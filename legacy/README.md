# Historical pre-RC.2 projects

For current development, open the root `HostsGuardian.sln`, which references only `rc2/` projects. The official Engine and WPF sources are documented in [Current State](../docs/CURRENT_STATE.md). Historical WPF checks remain separate from current executable WPF acceptance.
